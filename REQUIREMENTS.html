1. サービス概要

1.1 サービス名

Digital Memorial（デジタル墓誌）

1.2 キャッチコピー

故人の記憶を、永遠に。そして、残された家族が困らないために。

1.3 サービスの目的

Digital Memorial は、以下の 2 つの課題を解決する Web サービスです。

課題 1：故人の記憶の保存と共有 - 墓前に QR コードを設置し、スマートフォンで故人の略歴・写真・メッセージを閲覧できる

課題 2：生前の終活準備 - 自分が亡くなった後に家族が困らないよう、相続・遺産・医療希望・連絡先などを事前に整理・記録できる - チェックリスト形式で準備の抜け漏れを防ぎ、完成度をスコアで可視化する

1.4 提供URL

環境 URL
本番（フロントエンド） https://digital-memorial.onrender.com
本番（API） https://digital-memorial-api.onrender.com

2. ターゲットユーザー

2.1 ユーザー種別

種別 説明 主な利用機能
終活ユーザー（主軸） 自身の終活を進めたい 50〜70 代 相続棚卸し・チェックリスト・エンディングノート
遺族ユーザー 故人の情報を登録・管理したい家族 墓誌作成・QR コード
参拝者 QR コードから墓誌を閲覧したい人 公開墓誌ページの閲覧
信頼者（受取人） 死後にデジタル遺品鍵でデータを受け取る家族 デジタル遺品鍵・閲覧

2.2 ペルソナ

ペルソナ A：終活ユーザー - 年齢：62 歳・男性 - 状況：定年退職を機に終活を意識し始めた - 課題：相続人が誰になるか・何を持っているかを整理したいが、紙だと管理しにくい - ゴール：子どもたちに迷惑をかけずに逝きたい

ペルソナ B：遺族ユーザー - 年齢：45 歳・女性 - 状況：母親を亡くし、お墓に QR コードを設置したい - 課題：写真やエピソードを後世に残したい - ゴール：参拝者にスマホで母の人生を知ってもらいたい

4.2 相続の棚卸し機能

終活ユーザーが「誰が何を法的に主張できるか」を可視化し、遺産紛争を事前に防ぐための機能。

Phase 1：家族構成・法定相続人の特定・法定相続分の計算

機能ID 機能名 説明
F-201 相続計画の作成 相続計画を新規作成（複数プラン対応）
F-202 家族構成の入力 配偶者・子・親・兄弟姉妹・孫・甥姪を登録（続柄・存命・養子・半血・相続放棄・欠格を設定可能）
F-203 法定相続人の自動判定 民法の順位規定に基づき相続人を自動判定
F-204 法定相続分の計算 法定相続人ごとの取り分（分数・パーセント・根拠条文）を表示
F-205 相続人マップの表示 家族構成をツリー図で可視化し、誰が相続人かを一目で確認
F-206 遺留分の計算・表示 各権利者の遺留分（最低保証額）を計算・表示

法定相続分の計算ルール

相続人の構成 配偶者 第1〜3順位
配偶者 ＋ 子（孫） 1/2 1/2 ÷ 人数（均等）
配偶者 ＋ 直系尊属 2/3 1/3 ÷ 人数（均等）
配偶者 ＋ 兄弟姉妹 3/4 1/4 ÷ 人数（均等）※半血は全血の 1/2
配偶者のみ 全部 —
子（孫）のみ — 全部 ÷ 人数（均等）
直系尊属のみ — 全部 ÷ 人数（均等）
兄弟姉妹のみ — 全部 ÷ 人数（均等）※半血は全血の 1/2

代襲相続のルール

元の相続人 代襲者 放棄時の代襲
子（死亡・欠格・廃除） 孫（直系卑属） なし（放棄は代襲を生まない）
兄弟姉妹（死亡・欠格・廃除） 甥・姪（1代のみ） なし

Phase 2：財産の棚卸し・配分シミュレーション

機能ID 機能名 説明
F-211 財産の入力・管理 資産（不動産・預貯金・有価証券・生命保険・退職金・その他）と負債を登録
F-212 正味遺産額の計算 資産合計 − 負債合計 = 正味遺産額を自動計算
F-213 相続税基礎控除の表示 「3,000万円 ＋ 600万円 × 法定相続人数」を参考表示
F-214 法定相続分通りの配分表示 正味遺産額を法定相続分で自動分配した結果を表示
F-215 カスタム配分シミュレーション スライダーで各人の取り分を変更し、遺留分との比較をリアルタイム表示

財産の種別

種別 内容 備考
不動産 自宅・土地・収益物件 路線価または固定資産税評価額を目安
預貯金 銀行・郵便局口座 —
有価証券 株式・投資信託・債券 —
生命保険金 死亡保険金（受取人指定あり） みなし相続財産（原則として遺産分割対象外）
退職金 死亡退職金 みなし相続財産
その他資産 骨董品・自動車・貴金属など —
負債 住宅ローン・カードローンなど マイナス計上

Phase 3：遺留分・争いリスク分析

機能ID 機能名 説明

F-222 遺留分侵害チェック カスタム配分で遺留分を侵害している場合に警告を表示

4.5 デジタル遺品鍵

死後に指定した信頼者（家族）が、ユーザーの終活データに安全にアクセスできる仕組み。

機能一覧

機能ID 機能名 説明
F-501 信頼者（受取人）の登録 名前・メールアドレスを登録（最大 3 名）
F-502 アクセス範囲の設定 信頼者ごとに「閲覧できる機能」を選択（例：相続情報のみ、全データ）
F-503 解除キーの発行 信頼者に対してアクセス用の解除キー（ URL ＋トークン）をメール送信
F-504 アクセス条件の設定 「信頼者 2 名以上が申請した場合に開錠」などの条件設定
F-505 死後アクセスのリクエスト 信頼者が解除キーを使ってアクセスをリクエスト
F-506 アクセス承認・開錠 条件を満たした場合にシステムが自動で信頼者にデータアクセスを許可
F-507 アクセスログの記録 いつ誰がアクセスしたかを記録
F-508 信頼者へのプレビュー通知 登録時に信頼者に「あなたが指定されました」メールを送信

アクセス条件の選択肢

条件 説明
信頼者 1 名が申請 1 名の申請で即時開錠
信頼者 2 名以上が申請 複数名の合意で開錠（不正防止）
登録者の死亡診断書アップロード後 書類確認後に手動開錠（将来対応）

セキュリティ要件（F-5xx 共通）

  • 解除キーは一時的なトークン（有効期限あり）
  • 信頼者のメールアドレス認証が必須
  • 開錠後もアクセスは読み取り専用（編集・削除不可）

4.6 リマインダー（メール通知）

終活情報を定期的に見直す習慣を促し、情報の陳腐化を防ぐための機能。

機能一覧

機能ID 機能名 説明
F-601 年次見直しリマインダー 毎年設定した月に「内容を見直しましょう」メールを送信
F-602 期限アラート 遺言書確認・保険更新などの期限が近づいたらメール通知
F-603 未完了タスクのリマインダー チェックリストで未完了のタスクを定期的にメール通知
F-604 信頼者への定期確認メール 登録した信頼者が現在も有効かを年に 1 度確認するメールを送信
F-605 通知設定の変更 通知を受け取る月・頻度・メールアドレスをユーザーが変更可能

メール通知の実装方針

  • 配信サービス：SendGrid（または AWS SES）
  • 送信タイミング：バッチ処理（毎日深夜 0 時に当日対象のメールを送信）
  • 配信停止：各メールに配信停止リンクを設置（CAN-SPAM / 特定電子メール法準拠）

5. 非機能要件

5.1 パフォーマンス

項目 要件
ページ初期表示 3 秒以内（モバイル 4G 回線）
API レスポンス 500ms 以内（95 パーセンタイル）
写真アップロード 10MB 以下のファイルを 10 秒以内

5.2 可用性

項目 要件
稼働率 99% 以上（月次）
計画停止 深夜 2〜4 時（メンテナンス枠）
バックエンド起動 Render 無料プランのスリープ対策として初回 60 秒以内に起動

5.3 スケーラビリティ

項目 要件

ファイルストレージ移行 ユーザー増加に応じてローカル → AWS S3 / Cloudflare R2 に移行

8. セキュリティ要件

8.1 認証・認可

要件 実装方針
パスワードのハッシュ化 bcrypt（コスト係数 12 以上）
セッション管理 JWT（有効期限 30 分、リフレッシュトークンで自動延長）
他ユーザーデータへのアクセス防止 API 側で user_id を検証（フロントエンドに依存しない）
HTTPS 強制 全通信を HTTPS で暗号化
CORS 設定 許可ドメインを明示的に限定

8.2 データ保護

要件 実装方針
終活データの暗号化 センシティブな項目（医療希望・遺言内容）はデータベース保存時に暗号化（検討）
ファイル名の匿名化 アップロードファイル名を UUID に変換
アップロードファイルの検証 MIME タイプと拡張子の一致を確認
SQL インジェクション対策 ORM（SQLAlchemy）を使用し、生 SQL を避ける
XSS 対策 React のデフォルト エスケープ + Content-Security-Policy ヘッダー

8.3 デジタル遺品鍵のセキュリティ

要件 実装方針
解除キーの保護 トークンはハッシュ化してデータベースに保存
トークンの有効期限 発行から 72 時間（申請用）・開錠後は無期限閲覧可
メール認証の強制 信頼者は解除キー使用前にメール認証必須
開錠後のアクセス制限 読み取り専用（編集・削除・ダウンロード制限）
アクセスログ 全アクセスを IP・タイムスタンプとともに記録

11. 用語集

用語 説明
終活 人生の終わりに向けた事前準備活動（就活・婚活と同様の造語）
法定相続人 民法により相続権が認められた人（配偶者・子・直系尊属・兄弟姉妹）
法定相続分 民法が定める各相続人の取り分の割合
代襲相続 本来の相続人が死亡・欠格・廃除された場合に、その子が代わりに相続すること
遺留分 遺言書に関わらず法定相続人（兄弟姉妹を除く）が最低限受け取れる権利
遺留分侵害額請求 遺留分を侵害された相続人が、侵害額相当の金銭を請求できる権利
みなし相続財産 生命保険金・退職金など、相続財産ではないが相続税の対象となるもの
特別受益 生前に特定の相続人が受けた贈与（遺産の前払いとみなされる場合がある）
寄与分 故人の財産維持・増加に特別な貢献をした相続人が主張できる取り分の加算
エンディングノート 医療・葬儀・財産など、死後に家族が困らないよう事前に記録しておくノート
デジタル遺品鍵 死後に指定した信頼者がデジタルデータにアクセスするための仕組み
PWA Progressive Web App。ネイティブアプリに近い体験を Web で実現する技術
